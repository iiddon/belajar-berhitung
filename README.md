# Pulau Hitung — Belajar Berhitung SD

Aplikasi web interaktif untuk belajar berhitung anak SD kelas 1–3, bergaya buku cerita. Anak berpetualang bersama **Kiko si kucing** menjelajahi pulau-pulau di peta laut.

## Cara memakai

Buka `index.html` di browser (HP, iPad/tablet, atau komputer). Tidak perlu instalasi. Tampilan otomatis menyesuaikan layar: di iPad aplikasi diperbesar sampai pas satu layar, baik tegak maupun mendatar. Internet hanya dibutuhkan untuk memuat huruf (Google Fonts). Tanpa internet, aplikasi tetap jalan dengan huruf bawaan.

Progres anak (bintang, stiker, baju Kiko, rekor) tersimpan di browser perangkat yang dipakai. Untuk pindah perangkat, pakai **Profil → Kode cadangan**.

## Pasang di layar utama HP/iPad

Aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/ (root)`), lalu buka https://iiddon.github.io/belajar-berhitung/ dan pilih **Tambahkan ke Layar Utama**. Aplikasi akan muncul dengan ikon Kiko dan terbuka layar penuh.

## Fitur

- **Peta Pulau:** Pulau Angka, Tambah, Kurang, Campur, Kali, dan Bagi, ditambah wilayah Jam, Uang, dan Ukur. Setiap pulau punya 8 level, disesuaikan untuk kelas 1, 2, dan 3.
- **Bos Penjaga Peti** di Level 8, peti harta karun, dan **sertifikat** yang bisa diunduh.
- **Soal interaktif:** pilih jawaban lalu konfirmasi, seret uang ke dompet, putar jarum jam, dan susun angka.
- **Petunjuk bertahap**, soal yang salah diulang, dan benda hitungan yang beragam.
- **Ruang Belajar:** penjelasan bergambar langkah demi langkah.
- **Tantangan:** Balap Perahu dan Misi Mingguan.
- **Koleksi:** album stiker bertema (stiker bisa diketuk untuk diperbesar), Lemari Kiko (warna, kacamata, topi, kalung), dan sertifikat.
- **Suara:** efek bunyi, musik latar, dan soal yang dibacakan.
- **Untuk orang tua dan guru:** laporan belajar, buka semua level, dan kode cadangan progres.
